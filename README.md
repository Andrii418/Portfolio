# Portfolio — Andrii Torianyk

 W tym repozytorium rozwijam swoje portfolio, w którym prezentuję projekty webowe, mobilne i inne aplikacje. Stronę można zobaczyć pod adresem [andrii418.github.io/Portfolio](https://andrii418.github.io/Portfolio/).

## Co znajdziesz na stronie

- Mój profil, technologie, z którymi pracuję, i odnośniki do projektów.
- Moje 17 projektów oraz osobne strony z opisami i galeriami.
- Wersje językowe PL, EN i UA, które można wybrać w nawigacji.
- Jasny i ciemny motyw.
- Formularz kontaktowy.
- Trzy wersje CV w PDF. Przycisk pobiera plik zgodny z wybranym językiem strony.

## Technologie

Zbudowałem portfolio jako statyczną stronę w HTML, CSS i JavaScript, bez frameworka ani procesu budowania. Tłumaczenia obsługuje `i18n.js`, wspólne interakcje `main.js`, a galerie projektów `projects/case-gallery.js`.



## Struktura projektu

| Ścieżka | Zawartość |
| --- | --- |
| `index.html`, `home.css`, `style.css` | Strona główna i wspólne style |
| `projects/` | Lista projektów, strony projektów, style i galerie |
| `contact/` | Strona i formularz kontaktowy |
| `assets/` | Obrazy oraz CV: `CV.pdf`, `CV-EN.pdf`, `CV-UA.pdf` |
| `i18n.js`, `main.js` | Tłumaczenia, motyw, nawigacja i obsługa formularza |
